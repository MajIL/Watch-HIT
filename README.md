# Watch-HIT

Projet Flutter pour une application de listes de films.

## Importer un projet Flutter déjà existant dans ce dépôt

Si ton projet Flutter existe déjà sur ta machine, voici la procédure simple :

1. Clone ce dépôt :
   ```bash
   git clone https://github.com/MajIL/Watch-HIT.git
   cd Watch-HIT
   ```
2. Copie le contenu de ton projet Flutter existant dans ce dossier `Watch-HIT/`
   (en gardant des fichiers comme `pubspec.yaml`, `lib/`, `test/`, `android/`, `ios/`, etc.).
3. Vérifie que tout fonctionne :
   ```bash
   flutter pub get
   flutter test
   flutter run
   ```
4. Envoie le projet sur GitHub :
   ```bash
   git add .
   git commit -m "Import existing Flutter project"
   git push origin main
   ```

## Démarrage rapide après import

```bash
flutter pub get
flutter run
```
